# 公开预览边界

此版允许用虚构数据试用完整工作流，不作为生产使用承诺。首发标记为 prerelease，内部包版本仍为 0.1.0。

## 已观察到的行为

本地 macOS + DeepSeek Harness 0.1.0-rc.6 已运行安装版与真实 DeepSeek-V4-Flash。最近一次有界复测生成 PRD4 并运行同一验证计划中的3个文本案例：客户计数、不同问题区分、模糊反馈、冲突与输入夹带指令。原 PRD 和旧运行记录未被覆盖。

本次4次模型调用不是完整基准测试，不代表所有输入都会正确。案例仍有重复解释和带预设的追问，结论保留为部分通过。PRD仍需核对前后条件与范围。此处不包含真实用户材料或完整模型响应。

## 安装包加载验证

当前候选 tgz 已通过 rc.6 插件命令装入独立的 DSH_HOME；bundle 自动登记，3082 回环页面出现工作台入口并可打开空项目界面。跳过模型配置，没有复制原账号配置或调用模型。验证复用本机 Harness 与依赖缓存，不是跨机器验证。

## 不能宣称的能力

- 自动替代产品经理、自动决定需求优先级或替用户验收。
- 任意网站/应用生成、录音转写、自动部署、外部系统集成。
- 所有平台或 Harness 版本兼容。
- 数据不上云：真实处理使用用户配置的模型服务。
- 已验证节省时间、提升收入、达到客户满意度等业务结果。

## 发布检查说明

代码测试、构建与静态包检查属于工程证据，不等于模型正确性。发布前扫描源码与可达历史的常见凭据特征，核对第三方声明和包文件清单；这种扫描不能保证发现所有敏感内容。

首版不包括个人本机配置、私有访谈、运行记录、桌面文件、涟漪组件或底图。历史设计和阶段报告应按各自时间与构建范围理解。
