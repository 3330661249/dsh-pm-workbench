# Compatibility

Target: macOS, single user, local Web profile, Chrome, Harness `0.1.0-rc.6`.

The generated-Typert route failed its historical matrix. Public Connection RPC
with strict shared schemas is the selected replacement design, but it has not
been implemented or verified from this tarball. Host load, Client load, RPC,
UI, storage, restart, remove, model and real-data compatibility are all
unestablished.

Any future Gate A′ is restricted to `127.0.0.1`, empty `trustedHosts`, a
loopback-only channel, an isolated profile and synthetic counter data.
