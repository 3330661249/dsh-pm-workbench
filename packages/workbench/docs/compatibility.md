# Compatibility

Target: macOS, single user, local Web profile, Chrome, Harness `0.1.0-rc.6`.

The generated-Typert route failed its historical matrix. Public Connection RPC
with strict shared schemas is the selected replacement. The current package
source implements only a strict synthetic `health` plus persistent-counter
Probe, one `/dsh-pm-workbench-v1` route configured for loopback authority, and
an additive launcher/overlay Client UI.

The real tgz has not been installed or loaded in an isolated Harness profile.
No browser round trip, real restart persistence, removal/reinstall behavior, or
coexistence with the existing chat and ripple theme has been observed. Harness
runtime compatibility and Gate A′ remain unestablished. Model calls, interview
analysis and real-data processing are not part of this Probe.

The next isolated runtime observation is restricted to `127.0.0.1`, empty
`trustedHosts`, a dynamically allocated port other than `3080`, a loopback-only
channel, a fresh profile and synthetic counter data.
